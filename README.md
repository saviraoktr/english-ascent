# English Ascent
A personal English-learning tracker to monitor progress from B1 to C1 and prepare for IELTS Academic. Features include daily study habits, curriculum tracking, a vocabulary bank, grammar error log, and IELTS mock test score tracking.

## About the Project
English Ascent is a personal dashboard for organizing and tracking my English-learning journey, from strengthening grammar foundations to developing fluency and preparing for IELTS.

It includes:
- Learning Roadmap: Three learning stages covering grammar, fluency, vocabulary, and IELTS preparation.
- Daily Habits: Track study sessions and maintain learning consistency.
- Vocabulary Bank: Save new words, expressions, meanings, and example sentences.
- Error Log: Record mistakes, corrections, and explanations.
- IELTS Score Tracker: Record mock test scores and monitor progress across all four skills.
- Progress Dashboard: Keep track of learning activities and overall progress.

## How It Was Made
This project was created through vibe coding, using AI assistance to turn an idea into a working website. It was built with HTML, CSS, and JavaScript, with browser local storage used to save progress.

## A Personal Project
This website was created for my own personal learning journey. It is shared publicly as a record of the project, not as a product or service. It is not intended for public use, redistribution, or repurposing.

This is an evolving personal project. Features and functionality may change as my learning needs develop.
